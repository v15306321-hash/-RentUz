Объекты

Изменения каталога сохраняются в этом браузере. Чтобы обновить каталог у всех посетителей, скачайте listings.js и замените им файл data/listings.js на хостинге.

Изображения сайта

Меняйте фон главной страницы, обложки категорий, городские изображения, предпросмотр ссылок и рекламный баннер. Для блока «Здесь могла быть ваша реклама» также можно отдельно изменить адрес перехода. Фото объектов редактируются внутри карточки.

После изменений скачайте site-assets.js и замените файл data/site-assets.js в репозитории сайта, затем отправьте commit/push в GitHub. После повторного развёртывания Render обновит баннер и ссылку для всех посетителей. До экспорта локальные изменения видны только в этом браузере.
