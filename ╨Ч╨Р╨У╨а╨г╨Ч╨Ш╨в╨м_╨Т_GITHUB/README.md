# RENT UZBEKISTAN — сайт аренды и продажи недвижимости

Откройте `index.html` в браузере или загрузите всю папку на хостинг (Netlify, GitHub Pages, любой обычный хостинг).

## Структура
- `index.html` — страница сайта
- `css/style.css` — оформление
- `js/app.js` — логика: поиск, избранное, галерея, страница объекта
- `data/listings.js` — статические/резервные объекты (меняются через админ-панель)
- `data/site-assets.js` — глобальные изображения сайта, экспортируются из админ-панели
- `js/config.js` — включение и адрес API, который отдаёт опубликованные объявления Telegram-бота
- `admin/index.html` — админ-панель (перед публикацией обязательно закройте её реальной серверной авторизацией или ограничением доступа хостинга)
- `assets/img/` — картинки сайта, `assets/photos/` — сюда кладите фото объектов
- `robots.txt`, `sitemap.xml` — для Google

## Перед публикацией
1. Замените `YOUR-DOMAIN.uz` на ваш домен в `index.html`, `robots.txt`, `sitemap.xml`.
2. В `js/app.js` найдите `const OWN=` и впишите реальный телефон — сейчас там заглушка. Для отдельного объекта телефон можно указать в админ-панели.
3. Подключите сайт к Google Search Console и отправьте `sitemap.xml`.

## Как менять объекты
1. Откройте `ваш-сайт/admin/` и войдите.
2. Добавьте, измените или удалите объект; статус меняется прямо в списке.
3. В форме объекта нажмите «Загрузить фотографии», выберите файлы с компьютера или телефона. Изображения автоматически оптимизируются и прикрепляются к объекту; вручную вводить URL или путь не нужно. Можно добавить до 12 фотографий на объект и удалить ненужные в предпросмотре.
4. Нажмите «Скачать listings.js» и замените им файл `data/listings.js` на хостинге — тогда изменения каталога увидят все посетители.
5. В блоке «Изображения сайта» можно заменить общие изображения интерфейса. Для баннера «Здесь могла быть ваша реклама» выберите карточку «Рекламный блок — изображение баннера», загрузите картинку, затем в поле ниже укажите URL и нажмите «Сохранить ссылку».
6. Нажмите «Скачать site-assets.js», замените файл `data/site-assets.js` в папке сайта, отправьте изменения в GitHub (commit/push) и дождитесь повторного развёртывания Render. Изображение и URL рекламного блока экспортируются вместе.

Админ-панель пока работает в браузере: загруженные фотографии объектов сохраняются в карточке объекта, а настройки общих изображений сайта, рекламного баннера и его URL — в `localStorage`. Поэтому изменения не становятся общедоступными, пока вы не экспортируете `site-assets.js`, замените им файл в репозитории и отправите commit/push в GitHub. Для публикации объявлений из бота нужен работающий API-сервис из проекта бота: см. отдельный архив Telegram-бота (файл `web_api.py`) и файл `js/config.js`. Пароль проверяется в браузере и защищает только от случайного входа. Для настоящей защиты ограничьте доступ к папке `admin/` на хостинге.

Объекты в `data/listings.js` — примеры. Замените их своими.

## Интеграция с Telegram-ботом

После размещения укажите в переменных Render для бота `SITE_API_ENABLED=true`, `SITE_API_PUBLIC_URL` и точный `SITE_API_CORS_ORIGINS`. Для Static Site задайте `RENT_API_BASE` с HTTPS-адресом Web Service бота/API: при сборке `render-build.sh` включит интеграцию в `js/config.js`. Объявления со статусом `published` автоматически подгружаются в каталог, а фотографии проксируются через Telegram-бота.

Админ-панель сохраняет пароль в JavaScript и не является настоящей системой защиты. Перед запуском на публичном домене её нужно закрыть серверной авторизацией или ограничением доступа на уровне хостинга.


## Размещение сайта на Render из общего GitHub-репозитория

Создайте Static Site, подключите общий репозиторий, задайте Root Directory `Сайт`, Build Command `bash render-build.sh`, Publish Directory `.`. В переменную окружения `RENT_API_BASE` внесите полный HTTPS-адрес Web Service бота/API. Скрипт `render-build.sh` сформирует включённый `js/config.js` для текущей сборки. Подробно: `../Документация/РАЗМЕЩЕНИЕ_RENDER_GITHUB.md`.
